# CodeAlpha AI Internship Project: Hybrid FAQ & Generative Chatbot

An intelligent, full-stack, production-quality AI FAQ Chatbot built for the **CodeAlpha Artificial Intelligence Internship**.

This application leverages a **hybrid intelligence architecture**: it first searches an indexed local knowledge base of 100+ Computer Science & AI questions using Natural Language Processing (TF-IDF + Cosine Similarity). If the query confidence falls below a configured threshold, it automatically delegates the query to the **Groq API (Llama 3 70B model)** for generative AI fallback responses.

---

## 🌟 Key Features

- **Hybrid Intelligence Flow**: Instant responses from localized FAQ database, falling back to Llama 3 via Groq API.
- **Glassmorphism UI**: Glassmorphic theme built with CSS3 custom variables and ambient gradients.
- **Dark & Light Mode**: Seamless theme toggling persisted across sessions.
- **Interactive Chat Interface**:
  - Distinct right/left message bubbles.
  - Live animated typing & server loading indicators.
  - Source tracking badges (*"Answer from FAQ"* vs *"Generated by AI"*).
  - One-click copy message button.
  - Timestamps for every message.
  - LocalStorage chat history preservation with Clear Chat functionality.
- **Robust NLP Pipeline**: NLTK preprocessing (lowercasing, punctuation stripping, tokenization, stopword removal, and wordnet lemmatization).
